# Video Asset Organizer｜视频素材整理器

把剪映中剪好的片段整理成可以搜索、复用的素材库。

观看片段，写下场景说明、标记人物。以后按内容找到素材，并查看它来自原视频的哪个时间段。

**v2.0 · Windows 64 位 · 本地使用**

[下载软件](https://github.com/sevenPot7/video-asset-organizer/releases/latest) · [问题反馈](https://github.com/sevenPot7/video-asset-organizer/issues)

## 下载安装

1. 打开上方“下载软件”，在下载列表中选择 `VideoAssetOrganizer-Portable-x64-v2.0.zip`。
2. 将压缩包完整解压到一个固定文件夹。
3. 双击 `VideoAssetOrganizer.exe` 启动。

无需安装 Python 或另外配置视频处理工具。请保留程序旁的 `_internal` 文件夹，不要只复制一个 EXE。

GitHub 的 `Source code (zip)` 是仓库文件，不是可直接运行的软件包。

## 从哪里开始？

### 方式一：只在剪映里切好片段，还没有导出视频

适合只做切割、暂时不需要保留剪映后期效果的素材。

1. 在首页点击“修改配置”，选择对应的剪映草稿文件夹。
2. 点击“扫描草稿”；已扫描过的草稿会显示“重新扫描”。
3. 点击“开始整理”，或双击一条素材，观看片段、填写场景说明和人物。
4. 需要独立视频时，再勾选素材，点击“批量生成视频”。

只要原视频可访问、片段来源准确且能安全播放，就可以直接预览对应区间，不必先生成视频。

> 原视频预览和软件生成的视频都不包含剪映中的降噪、字幕、调色、特效等后期处理。需要这些效果时，请使用下面的方式二。

### 方式二：已经从剪映导出了多个片段视频

适合需要保留剪映剪辑效果的素材。

1. 先扫描对应的剪映草稿。
2. 点击“关联剪映成片”，选择存放这些独立视频的文件夹。
3. 核对软件提供的对应关系；不确定的条目可以跳过或手动更换视频。
4. 确认后即可预览成片、填写说明和人物，不需要再生成一次视频。

“关联”就是告诉软件：**这条素材对应这个视频文件。** 它不会复制、移动或重新剪辑视频。

单条素材也可以在预览窗口点击“关联已有视频”。复合片段可以关联剪映导出的完整片段视频，再按一条素材整理。

文件编号和时长只是匹配线索，不能代替画面核对。这里需要的是一个文件夹里的多个独立片段，不是整条时间线的一部长视频。

### 方式三：只有视频文件夹，没有剪映草稿

使用“更多工具 → 导入普通视频”，选择文件夹即可开始整理。

软件把每个视频作为一条素材，你可以预览、填写说明、标记人物和搜索。它不会自动把长视频切成片段，也不能仅凭已导出的视频还原原录像的时间位置。需要保留草稿中的来源时间时，请使用前两种方式。

## 日常整理与查找

### 写下以后能搜到的说明

例如：`两人在直播间对视后大笑，适合做搞笑转场`。比只写“好用”“片段1”更容易找回素材。

- 场景说明和人物由你填写，当前版本没有自动识别功能。
- 右侧会显示“未保存更改”“已保存”等保存状态。
- 点击“保存并播放下一个”或按 `Ctrl+Enter`，先保存，再播放下一条。
- 手动点击上一条、下一条时，显示起始画面并暂停；切换或关闭预览也会按自动保存规则保存。
- 连续播放默认关闭，需要时再开启。开始编辑说明或人物后会停止连续跳转。

上一条、下一条按当前列表的筛选和排序顺序切换。

### 去素材库按内容找视频

左侧“素材库”可以跨草稿搜索场景说明、人物、视频名称等信息，再直接预览或打开视频所在目录。

- 首页侧重按时间线逐条整理，素材库侧重日后检索。
- “原视频时间”是片段在原录像中的位置；“时间线位置”是它在剪映草稿中的位置，两者不是一回事。
- 名称、说明等长文本列可以拖动表头分隔线调整宽度；时间、状态等短字段采用固定宽度。
- 筛选只影响显示，不会删除素材。“清除筛选”可恢复当前页面的默认查看范围；首页会保留当前草稿。

## 生成视频、命名与来源限制

点击“批量生成视频”后，先确认处理范围、数量、保存目录、命名和画质，再开始生成。

生成窗口可以直接选择命名规则，仅用于本次生成：

| 命名方式 | 文件名示例 |
| --- | --- |
| 全素材统一编号 | `L000001.mp4` |
| 原视频名称 + 序号 | `直播原片_001.mp4` |
| 草稿名称 + 序号 | `10月6日_001.mp4` |
| 自定义名称 + 序号 | `香港直播_001.mp4` |

示例用于说明命名形式，实际序号及名称以本次生成结果为准。单条生成也支持直接修改文件名。

已有视频默认保留。需要重新生成时，请看清确认窗口中的处理方式；不修改命名时沿用原有生成行为，主动选择新规则则创建新文件并保留旧文件。软件生成的视频还可以通过右键菜单重命名。

**软件不是剪映的渲染器。** 多段复合、变速、倒放、叠层等情况，不一定能从原视频安全生成，也不能据此还原剪映效果。遇到限制时会显示原因；需要完整效果，请关联剪映导出的成片。

复合片段可以保留多段已识别来源。显示“部分来源已识别”时，表示来源还不完整；即使关联了视频，也不代表全部来源已经核实。可在预览中展开“来源明细”查看。

## 导出 Excel / CSV 素材目录

点击“导出素材目录”，选择已勾选素材或其他需要的范围，确认数量后保存。

Excel 包含三个工作表：

- **素材索引**：日常查找用，包含视频名称、场景说明、人物、来源时间及打开视频的链接。
- **来源明细**：逐段保留已识别的来源，复合片段的多段时间不会合并成一段。
- **管理信息**：保留文件路径及其他核对信息，平时不需要填写。

CSV 同样保留说明、人物及多段来源信息。导出的是素材目录，不是把视频一起打包。

视频链接依赖本机路径。视频被移动、删除，或把表格发到另一台电脑后，链接可能失效；本地预览使用的原视频也不等于已经生成了独立片段。

## 想从头重新整理？

**重新扫描或导入是刷新素材，不是清空以前的整理内容。** 同一条素材能被识别时，会保留已有说明、人物及视频关联。

需要从头标注时：

1. 筛选并勾选要重新整理的素材。
2. 在“更多工具”的数据管理区点击“重置整理内容”；素材库也有同名入口。
3. 选择清除场景说明、相关人物，或两项一起清除。
4. 看清实际影响的数量，再确认。

默认只勾选场景说明。操作保留素材记录、视频文件、文件名、来源时间及关联，执行前自动备份。关闭软件前，可以用“撤销上一步”恢复；关闭后会话撤销不可用，但备份仍保留。

“隐藏扫描记录”只是把记录从当前结果中隐藏，与“重置整理内容”不同，不会清除说明或删除视频。

## 数据保存与更新

场景说明、人物、来源时间和视频对应关系保存在本机素材库中，视频仍放在原来的文件夹。

正式版数据目录：

```text
%LOCALAPPDATA%\JianyingLiveOrganizer
```

在资源管理器地址栏粘贴上面这行，按回车即可打开。备份时先关闭软件，再复制整个目录；原视频、剪映草稿和成片需要另外备份。

- 扫描草稿只读取原文件，不修改剪映草稿或原视频。
- 视频被删除后，说明仍在。软件生成的片段可在原视频仍可用、满足截取条件时重新生成；剪映成片则需重新从剪映导出并关联。
- 不要为了换视频名称、重新生成或重新标注而删除整个数据目录。
- 普通视频文件夹主要按路径和时长识别文件。改名、移动或替换文件后，重新导入不保证还能接回原记录。

更新时先关闭软件，备份数据，再完整解压新版。正式版仍读取同一数据目录，不必重新扫描。若更换了程序保存位置，桌面快捷方式也要指向新位置。

“检查更新”负责提示新版，不会自动安装或替换程序。无法连接 GitHub 时，可以手动打开本页上方的下载链接；无法检查更新不影响本地整理。

## 飞书同步（可选）

不使用飞书也可以完成本地整理、搜索和表格导出。

需要把素材目录放到飞书多维表格时，在“设置 → 飞书连接设置”中按说明配置，再进入左侧“飞书同步”操作。首次使用需要在[飞书开放平台](https://open.feishu.cn/)创建应用、取得连接参数，并给应用访问目标表格的权限。

多维表格链接中，`/base/` 后面的一段通常是 App Token，`table=` 后面的一段是 Table ID；具体填写和表格字段要求请查看软件内的连接说明。

同步的是说明、人物、时间及文件路径等记录，**不会上传本地视频**。其他电脑不能仅凭这些路径访问你电脑里的文件。

## 常见问题与反馈

**无法预览怎么办？**

先看提示：可能是文件被移动或删除，也可能是片段来源不能安全播放。可重新定位文件，或关联剪映导出的对应视频；没有视频时仍能填写说明和人物。

**为什么草稿读不到？**

部分新版加密草稿需要本机安装相兼容的剪映专业版才能读取。不同剪映版本和复杂草稿可能存在兼容性限制，请保留具体报错反馈。

**反馈问题时提供什么？**

请在[问题反馈](https://github.com/sevenPot7/video-asset-organizer/issues)中提供软件版本、操作步骤、预期结果、实际现象及截图。日志位于数据目录下的 `logs\app.log`。提交前请遮挡个人路径、客户信息和飞书密钥，不要公开上传完整素材库或私人视频。
