# 视频素材整理器｜Video Asset Organizer

Windows 桌面工具，用于从剪映草稿中提取视频片段，整理场景说明和相关人物，导出独立视频，并同步到飞书多维表格。

## 下载

[下载最新版](https://github.com/sevenPot7/video-asset-organizer/releases/latest)

请在 Release 页面中的 **Assets** 区域下载：

`VideoAssetOrganizer-Portable-x64-v1.0.0.zip`

不要下载 `Source code (zip)`，那个不是可运行程序。

## 安装

1. 下载 ZIP 文件。
2. 解压整个文件夹。
3. 双击 `VideoAssetOrganizer.exe`。
4. 不要只复制 EXE，`_internal` 文件夹必须保留。
5. 不需要额外安装 Python 或 FFmpeg。

## 基本用法

### 扫描剪映草稿

1. 选择剪映草稿文件夹。
2. 选择素材输出目录。
3. 点击“开始扫描草稿”。
4. 在素材列表中预览和整理片段。
5. 选择片段后导出视频或同步到飞书。

### 导入已有视频

如果视频不在剪映草稿中，可以使用：

`更多 → 导入已有视频（非剪映草稿）`

选择视频文件夹后，软件会为每个完整视频建立一条素材记录。

此功能不会自动切片；需要从剪映草稿提取片段时，请使用“扫描草稿”。

## 整理素材

预览片段时可以填写：

- 场景说明
- 相关人物
- 使用项目
- 备注

相关人物支持标签选择，也可以新增人物标签。

## 飞书同步

首次使用前，在“设置”中填写：

- App ID
- App Secret
- App Token
- Table ID

只有点击同步后，素材信息才会写入飞书。

## 数据和隐私

- 剪映草稿只读，不会被修改或删除。
- 软件数据保存在：

  `%LOCALAPPDATA%\JianyingLiveOrganizer`

- 飞书密钥保存在 Windows 凭据管理器中。
- 请不要把个人的 `settings.json`、数据库、日志或剪映草稿上传到 GitHub。

发现新版本后，软件会显示更新说明并打开下载页面。下载新版本后，关闭旧软件，解压新版文件夹即可。

## 常见问题

### Windows 弹出安全提示

请确认文件来自本仓库的 Release 页面。未签名的新 Windows 程序可能会出现安全提示。

### 找不到原视频

请在项目配置中设置“原视频搜索目录”，或者使用“重新定位原视频”。

### 加密草稿无法读取

请确认电脑安装了兼容版本的剪映专业版。
