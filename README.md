# Video Asset Organizer｜视频素材整理器

Windows 本地桌面工具：只读扫描剪映专业版草稿或导入普通视频文件夹，将素材索引到 SQLite，支持区间预览、人工整理标签、按源视频时间精确导出独立 MP4，并可导出 Excel/CSV 或同步飞书多维表格。

当前公开版本：`v1.0.0`。软件本身免费使用，也可以用于商业视频素材工作流；未经作者书面许可，不得销售、出租、收费下载、收费授权，或将软件打包进收费软件、让客户付费获得软件访问权，或放入广告套餐。具体条款见 `LICENSE`。

## 安全边界

- 草稿目录永远只读。程序不会覆盖、修改、删除或移动 `draft_content.json`、`subdraft`、`Timelines` 或原视频。
- 所有应用数据写入 `%LOCALAPPDATA%\JianyingLiveOrganizer`；媒体只写入用户指定的输出目录。
- 加密草稿只通过剪映安装目录中的 `videoeditor.dll` 对临时副本解密；原草稿不会被解密或回写。
- 复杂复合片段会明确标记并拒绝直接切片，避免生成内容错误的视频。

## 安装

普通用户请下载 `VideoAssetOrganizer-Portable-x64-v1.0.0.zip`，完整解压后双击 `VideoAssetOrganizer.exe`。不要只复制 EXE；`_internal` 目录是运行所必需的。无需另装 Python 或配置 FFmpeg PATH。

第一次在其他电脑验证时，请按 `CLEAN_PC_TEST.md` 的顺序测试。

读取新版加密草稿时，目标电脑仍需安装相兼容的剪映专业版；处理未加密草稿或普通视频文件夹不依赖剪映。第一次公开测试建议保留 ZIP，不要直接覆盖旧版本目录。

### 自动检查更新

程序启动后会在首页显示后静默检查 GitHub Release（同一台电脑最多每 6 小时检查一次）。如果发现比当前版本更新的版本，会显示更新说明；点击“打开下载页”即可在 Release 页面下载新版。本版本只负责识别和提示，不会在后台替换正在运行的文件。

发布新版本时，请先修改 `app_info.py` 中的 `APP_VERSION`，再运行构建脚本，最后在 GitHub 创建同名标签的 Release 并上传新的 ZIP。不要覆盖旧 Release，也不要把 `settings.json`、数据库、日志、剪映草稿或飞书密钥上传到仓库。

下面内容仅供开发者从源码运行：

在 PowerShell 中进入本目录后运行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_app.py
```

开发者可使用上述命令从源码运行。普通用户及本机日常使用请直接运行打包后的 `VideoAssetOrganizer.exe`。

## 使用方法

### 1. 完成路径与导出设置

- 已保存草稿路径和输出目录时，程序启动后会自动收起“项目配置”，为素材列表保留更多空间。点击“展开配置”可以随时查看或修改设置。
- **草稿路径**：选择一个剪映草稿文件夹，用于扫描该草稿中的视频片段。
- **素材输出路径**：选择导出后的视频文件保存位置。程序只会向该目录写入媒体文件。
- **源视频搜索目录**：选填。原视频移动后，程序可在此目录中按文件名尝试重新定位；多个目录用分号分隔。
- **命名规则**：决定导出文件的名称。一般建议使用“原视频名 + 序号”。
- **导出模式**：一般建议使用“精确剪切”，它会重新编码并准确保留设定的起止位置。“快速剪切”直接复制原视频码流，通常快很多、资源占用低且没有二次压缩损失，但起止位置可能移动到附近关键帧。
- **导出画质**：点击导出后，软件会读取本次原视频的实际尺寸，例如显示“原分辨率（1920×1080）”。固定画质选项不会高于原视频：1080p 原片最高只能选择 1080p，720p 原片最高只能选择 720p；混合导出时以其中最低分辨率为上限。

### 2. 扫描或导入素材

- **扫描草稿**：扫描“草稿路径”中指定的单个剪映草稿。
- **更多 → 批量扫描草稿**：选择一个草稿总目录，程序会自动查找其中包含 `draft_content.json` 的草稿并逐个扫描。某个草稿扫描失败时，不会中断其他草稿。
- **更多 → 导入已有视频（非剪映草稿）**：不依赖剪映草稿，直接递归导入普通视频文件。支持 MP4、MOV、MKV、AVI、M4V、WebM、MTS、M2TS 和 TS。

扫描剪映草稿时仅会读取文件，不会修改草稿内容或原视频。

### 3. 查找与选择素材

- 搜索框可以按文件名、草稿名称或复合片段名称查找素材。
- 筛选栏可以按草稿、原视频、复合片段、导出状态和飞书状态组合筛选。
- **全选结果**：勾选筛选后当前显示的全部素材。
- **清除选择**：取消所有勾选。
- **反选**：将当前显示素材的勾选状态全部反转。

筛选只改变列表的显示范围，不会删除素材记录或视频文件。

### 4. 预览素材

- 单击一条素材后点击“预览片段”，或者直接双击素材行，即可打开预览窗口。
- “上一个”和“下一个”按照当前列表的筛选及排序顺序切换素材。
- 键盘左右方向键也可以切换素材，空格键用于播放或暂停。
- “播完自动下一个”默认开启；取消勾选后，当前片段播放结束时会停在片段末尾。

扫描结果属于软件自己的索引，不会写回剪映草稿。若需要重新读取当前草稿，点击“清空当前结果”，确认后再点击“扫描草稿”。清空只会把当前草稿的扫描记录暂时隐藏，不会删除草稿、原视频、导出文件、场景说明、人物、备注、导出状态或飞书绑定；重新扫描后会自动恢复原有整理信息。清空后也可用“撤销上一步”立即恢复显示。

### 5. 填写整理信息

预览素材时可以填写场景说明和相关人物。场景说明用于记录动作、画面内容、氛围或适用场景；相关人物可通过标签多选，也可以现场新增常用人物标签，并将当前选择设为该草稿的默认人物。默认值只用于人物为空的片段，不覆盖已有内容。

以上信息均由使用者人工填写，当前版本不会调用 AI。预览素材时，视频右侧可以多选相关人物并填写场景说明；点击“保存并下一个”或按 `Ctrl+Enter` 可一并保存并切换素材，直接切换或关闭预览窗口时也会自动保存。

### 6. 重新定位原视频与撤销

原视频移动或改名后，选中一个关联片段并点击“重新定位原视频”，然后选择新文件。同一原视频关联的全部片段会同时更新路径。

“撤销上一步”可以恢复最近一次清空扫描结果或原视频重新定位。最多保留本次运行期间最近 20 次可撤销操作；关闭程序后撤销记录不会保留。预览中保存的场景说明和人物会直接写入本地索引，导出文件和飞书远端写入也不属于可撤销范围。清空前的确认框会显示包含人工整理信息的记录数以及已同步、未同步的飞书记录数；未同步内容仍会保存在本机，但不会自动写入飞书。

### 7. 导出视频片段

- **导出全部**：导出数据库中的全部素材；已经成功导出且文件仍然存在的素材会自动跳过。
- **导出选中**：只导出已经勾选的素材，并允许重新生成已有输出文件。
- **导出 Excel / CSV**：导出素材索引和人工整理信息。该按钮已放在主操作区，便于日常使用。
- **右键 → 重新导出此片段**：只重新导出鼠标所在的单条素材，并覆盖该素材原有的输出文件。

精确模式会优先尝试 NVIDIA、Intel 或 AMD 硬件 H.264 编码器；硬件编码不可用时自动改用 `libx264`。每个输出文件都会通过 ffprobe 检查，精确模式默认允许 0.15 秒的时长误差。

### 8. 导出 Excel 或 CSV 索引

点击“导出 Excel / CSV”，可以将片段名称、场景说明、相关人物、草稿和原视频信息及管理信息保存为 `.xlsx` 或 `.csv` 文件。XLSX 文件包含“素材索引”和“管理信息”两个 Sheet：前者用于日常查找，后者保存本地路径、导出状态、备注及内部 Clip UID。CSV 不支持多 Sheet，因此会将两部分内容合并为一张表。导出窗口会根据当前素材的草稿名称自动建议“草稿名素材索引.xlsx”；如果包含多个草稿，则使用“视频素材索引.xlsx”。此操作只导出索引信息，不会复制视频文件。

### 9. 同步飞书多维表格

首次使用前，请先按照下方“飞书准备”完成连接配置。同步范围包括：

- **同步勾选片段**：只同步已经勾选的素材；
- **同步全部素材**：同步数据库中的全部素材。

开始同步前，程序会显示预计新增、更新和跳过的记录数量。与上次成功同步内容完全相同的记录会自动跳过。首次使用内容校验功能同步时，程序需要建立校验信息，因此部分原有记录可能显示为“更新”。

在素材行上点击右键并选择“重新同步此片段到飞书”，可以仅处理该条素材。程序会优先根据已保存的飞书记录 ID 更新原记录。

### 10. 右键菜单

在任意素材行上点击鼠标右键，可以执行单条素材操作，包括预览、重新导出、重新同步、重新定位原视频、使用系统播放器打开、打开文件所在位置，以及复制文件名、时间段或路径。

## 飞书准备

在飞书开放平台创建企业自建应用，启用多维表格读写权限，将应用添加为多维表格协作者，然后在设置中填写 App ID、App Secret、App Token 与 Table ID。字段映射是可编辑 JSON；远端字段类型需与写入值兼容。

SQLite 是唯一主索引。飞书离线或失败不会影响扫描、媒体导出和表格导出。App Secret 只保存在 Windows 凭据管理器；凭据管理器不可用时软件会拒绝明文保存。

## 数据稳定性

`clip_uid = SHA256(normalized_source_path | source_start_us | source_duration_us)`。重扫已有 Clip UID 时保留文件名、序号、输出路径、导出状态、飞书记录 ID 和未来 AI 数据。草稿中已删除的旧片段只标为 `missing_from_draft = true`，不会删除本地 MP4。
